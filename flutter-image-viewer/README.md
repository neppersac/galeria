# Flutter Image Viewer

A Flutter application that displays images from an Android device. The app shows thumbnails of all images and allows users to select a specific folder to filter the images displayed. When an image is selected, it opens in full screen.

## Features

- Displays a grid of image thumbnails.
- Allows users to select a specific folder to view images.
- Opens selected images in full screen.

## Getting Started

### Prerequisites

- Flutter SDK installed on your machine.
- An Android device or emulator to run the application.

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/flutter-image-viewer.git
   ```

2. Navigate to the project directory:
   ```
   cd flutter-image-viewer
   ```

3. Install the dependencies:
   ```
   flutter pub get
   ```

### Running the App

To run the application, use the following command:
```
flutter run
```

### Folder Selection

The app allows users to select a specific folder from which to display images. This feature enhances the user experience by enabling focused browsing of images.
